# Математика және логика: деңгейді анықтау тесті

Оқушы сайтқа кіріп, математика мен логика бойынша 20 сұрақтан тұратын аналитикалық тест тапсырады.
Тест аяқталған соң оқушыға **нәтиже көрсетілмейді** — тек «тест қабылданды» деген хабар шығады.
Нәтижені (балл, деңгей, толтыру керек тақырыптар, білетін тақырыптар, әр сұрақ бойынша талдау) тек **админ** көреді.

## Іске қосу

Node.js 18+ қажет, сыртқы тәуелділіктер жоқ.

```bash
ADMIN_PASSWORD='күшті-құпиясөз' npm start
```

- Тест беті: http://localhost:3000/
- Админ панелі: http://localhost:3000/admin

| Айнымалы | Мағынасы | Әдепкі |
|---|---|---|
| `ADMIN_PASSWORD` | Админ құпиясөзі | `admin123` (міндетті түрде өзгертіңіз) |
| `PORT` | Порт | `3000` |
| `DATA_FILE` | Нәтижелер сақталатын файл | `data/results.json` |

## Тест құрылымы

10 тақырып, әр тақырыпта 2 сұрақтан (барлығы 20):
арифметикалық амалдар, жай бөлшектер, пайыздар, теңдеулер, мәтінді есептер, геометрия,
сан тізбектері мен заңдылықтар, логикалық ой қорыту, комбинаторика, ықтималдық.

Сұрақтар мен дұрыс жауаптар `src/questions.js` файлында (тек серверде, оқушының браузеріне жіберілмейді).

## Бағалау

- **Балл** — дұрыс жауаптар саны (20-дан).
- **Деңгей**: 18–20 — Жоғары, 14–17 — Жақсы, 8–13 — Орташа, 0–7 — Төмен.
- **Білетін тақырыптары** — тақырыптың екі сұрағына да дұрыс жауап берілген.
- **Толтыру керек тақырыптар** — кемінде бір қате бар; әр тақырыпқа ұсыныс беріледі, ең әлсіз тақырыптар бірінші тұрады.
